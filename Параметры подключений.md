
## ## 1. Сетевые настройки (TCP/IP)
*   **`listen_addresses`**: Определяет IP-адреса (интерфейсы), на которых сервер будет слушать входящие подключения.
    *   `'*'`: Слушать все интерфейсы (стандарт для работы в сети).
    *   `'localhost'`: Только локальные подключения внутри сервера.
    *   `'10.0.0.1, localhost'`: Слушать только конкретный частный IP и самого себя.
    *   **Применение:** Требуется `restart`.
*   **`port`**: Задает номер TCP-порта. По умолчанию `5432`.
    *   Полезно менять для запуска нескольких экземпляров PostgreSQL на одном сервере.
    *   **Применение:** Требуется `restart`.

## ## 2. Лимиты и резервирование соединений
*   **`max_connections`**: Максимальное количество одновременных подключений.
    *   Каждое соединение создает процесс в ОС и потребляет RAM (~10-20 МБ + `work_mem`).
    *   Не рекомендуется завышать без пулеров (PgBouncer), так как это снижает производительность CPU.
    *   **Применение:** Требуется `restart`.
*   **`superuser_reserved_connections`**: Количество слотов, зарезервированных для суперпользователей (`postgres`).
    *   Позволяет админу зайти в базу, даже если обычные пользователи заняли все доступные лимиты.
    *   **Применение:** Требуется `restart`.
*   **`reserved_connections`** (PostgreSQL 16+): Резерв для ролей с правом `pg_use_reserved_connections`.
    *   Используется для бесперебойной работы систем мониторинга или бэкапов.
    *   **Применение:** Требуется `restart`.

## ## 3. Локальные сокеты (Unix Sockets)
*   **`unix_socket_directories`**: Список папок, в которых сервер создает Unix-сокет для локального обмена данными.
    *   Работа через сокет на 10-15% быстрее, чем через TCP/IP (localhost).
    *   **Применение:** Требуется `restart`.
*   **`unix_socket_group`**: Задает группу ОС, которая будет владеть файлом сокета.
    *   Позволяет пользователям из этой группы (например, `www-data`) подключаться к сокету.
    *   **Применение:** Требуется `restart`.
*   **`unix_socket_permissions`**: Устанавливает права доступа на файл сокета в формате Unix (права доступа).
    *   `0777`: Разрешить подключаться всем пользователям сервера (по умолчанию).
    *   `0700`: Только владелец процесса postgres может использовать сокет.
    *   **Применение:** Требуется `restart`.

## ## 4. Контроль «мёртвых» соединений (Keepalives)
*   **`tcp_keepalives_idle`**, **`interval`**, **`count`**: Настройки проверки активности клиента.
    *   Помогают серверу быстрее разорвать связь и освободить слот в `max_connections`, если клиент «умер» или пропал интернет.
    *   **Применение:** Достаточно `reload`.
