# Тема 2: Использование psql

## 1. Подключение и навигация
*   **Подключение:**
    ```bash
    psql -d dbname -U username -h host -p 5432
    ```
*   `\conninfo`: Информация о текущем подключении (под каким пользователем, к какой базе, через какой сокет/IP).
*   `\! <команда>`: Выполнить команду терминала (Linux) не выходя из psql.
    *   Пример: `\! pwd` (показать текущую папку).

## 2. Форматирование вывода
*   `\x`: **Expanded display** (Расширенный режим). Переключает вывод из табличного (строки) в вертикальный (карточки). Незаменимо для широких таблиц, не влезающих в экран.
*   `\a`: Переключает выравнивание (Aligned/Unaligned). Полезно, если нужно скопировать данные в другой файл без лишних пробелов.
*   `\t`: **Tuples only**. Убирает "шапку" (заголовки столбцов) и "подвал" (надпись "row(s)"). Оставляет только "голые" данные.

## 3. Работа с выводом и буфером
*   `\o <файл>`: Перенаправляет весь дальнейший вывод запросов в файл.
    *   Чтобы перестать писать в файл и вернуть вывод на экран, нужно ввести `\o` без аргументов.
*   `\setenv KEY VALUE`: Устанавливает переменную окружения ОС для текущей сессии psql.

## 4. Продвинутое выполнение команд (\g и \gexec)

### Команда \g
Используется для отправки текущего буфера запроса на выполнение (аналог `;`), но с дополнительными возможностями:
1.  **Запись в файл (разово):** `SELECT * FROM users \g my_file.txt`
2.  **Передача в pipe (Linux):** `SELECT * FROM users \g | grep "admin"`
3.  **С одноразовыми настройками:**
    ```sql
    SELECT * FROM my_table 
    \g (format=unaligned tuples_only=on)
    ```
    *Это выполнит запрос, убрав рамки и заголовки только для этого вывода, не меняя глобальные настройки сессии.*

### Команда \gexec
Используется для **выполнения сгенерированного SQL-кода**.
Psql берет результат предыдущего запроса и выполняет его как новые SQL-команды.

**Пример (Генерация SQL):**
Задача: Сделать `VACUUM` для всех таблиц в схеме `public`.
```sql
SELECT 'VACUUM ANALYZE ' || tablename || ';'
FROM pg_tables
WHERE schemaname = 'public'
\gexec
```
1. Первый `SELECT` формирует список строк вида `VACUUM ANALYZE table1;`.
2. `\gexec` берет эти строки и выполняет их одну за другой.

---
**Практика:**
Попробуй с помощью `\gexec` создать запрос, который выведет команду `SELECT count(*) FROM ...;` для каждой таблицы в базе, а потом выполнит их.
